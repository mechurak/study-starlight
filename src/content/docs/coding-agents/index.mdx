<Thesis>프로젝트 규칙은 공유하고, 큰 작업은 목표·완료 조건·현재 상태를 남겨 어느 도구에서든 이어 간다</Thesis>

Codex에서 정한 결정을 Claude Code가 모르거나, 새 세션이 이미 끝난 작업을 반복하는 문제에서 출발한다.
이 덱은 Git·Markdown·기본 명령 실행을 아는 독자가 **자신의 프로젝트에 맞는 AGENTS.md와 작업 지침을
만들고, 큰 작업을 여러 세션에 걸쳐 구현·검증·인계하는 방법**을 다룬다.

기존 레포의 명령과 문서를 확인해 공유 지침을 개선한 뒤, 목표와 완료 조건을 계획에 남기고,
실행 결과를 기록해 다음 세션으로 넘긴다. 설명용 사례는 기존 업무 서비스의 CSV 내보내기다.
이 사이트의 덱 작성 규칙이나 파일 번호를 다른 프로젝트에 그대로 복사할 필요는 없다.

## 읽은 뒤 확인할 것

이전 대화 없이도 새 에이전트가 현재 목표와 다음 작업을 찾을 수 있어야 한다.
완료를 주장할 때에는 해당 요구사항을 만족하는 실제 동작과 검증 결과를 가리킨다.
문서 수나 계획의 길이는 성공 기준이 아니다.

2026-09-19에 공식 자료와 공개 레포를 대조했다. 도구별 실제 세션 로딩이나 예시 서비스의 구현을
실측한 결과는 아니다. 제품 동작은 공식 근거로, 운영안은 적용 조건으로 구분해 설명한다.
