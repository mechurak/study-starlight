## 신원과 로그인

| 용어 | 뜻 | 자세히 |
|---|---|---|
| authentication / authorization | 누구인지 확인 / 무엇을 허용할지 판단 | [Keycloak의 역할](/keycloak/keycloak-overview/) |
| IdP | 사용자를 인증하고 신원 결과를 제공하는 주체 | [Identity Brokering](/keycloak/identity-brokering/) |
| realm | 사용자·client·role·정책을 격리한 Keycloak 영역 | [Realm과 사용자](/keycloak/realm-and-users/) |
| SSO | 한 realm 로그인 session을 여러 client가 재사용하는 경험 | [Client와 SSO](/keycloak/clients-and-sso/) |
| MFA / TOTP | password 외 요소 / 시간 기반 일회용 code | [인증 Flow와 OTP](/keycloak/authentication-flows/) |
| Identity Brokering | browser를 외부 IdP로 보내 인증 결과를 local user에 연결 | [Identity Brokering](/keycloak/identity-brokering/) |

## 요약

- 인증과 인가, Federation과 Brokering, LDAP mapper와 protocol mapper를 서로 다른 경계로 본다.
- ID/access/refresh token은 소비자와 목적이 다르며 JWT라는 형식만으로 안전해지지 않는다.
- 용어의 실제 설정과 검증 절차는 표의 질문 중심 페이지에서 다시 확인한다.
