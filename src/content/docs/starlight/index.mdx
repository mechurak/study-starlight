## 전체를 관통하는 두 문장

**콘텐츠 · 구조 · 표현은 다른 층이다.** 글은 `src/content/docs/`의 마크다운,
덱 설정은 각 폴더의 `_deck.mjs`와 페이지 frontmatter, 전역 어휘는 `src/data/catalog.mjs`,
사이트 설정은 `astro.config.mjs`, 시각 패턴은 `src/components/` — 층이 분리되어 있어서
글을 고치다 사이트 구조를 깨뜨릴 가능성을 줄이고, 구조를 바꿔도 본문은 그대로 남는다.
무언가 이상하면 "어느 층인가"부터 묻는다.

**빌드 통과가 끝이 아니다.** MDX 문법과 D2 문법, 렌더된 내부 링크는 자동 검사가 잡지만, 깨진 굵게 ·
모바일 넘침 · D2의 최종 색과 확대는 **빌드가 통과한 채로 깨져 있다.** 고친 것에 맞는 판정자
(브라우저 두 테마, grep)를 골라 쓰는 것까지가 수정이다([8장](/starlight/08-pipeline/)).
