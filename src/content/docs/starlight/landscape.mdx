## 문서를 두는 곳은 세 부류다

| 방식 | 편집·보관의 중심 | 선택 전에 확인할 것 |
|---|---|---|
| 서비스형 위키 | 화면 편집·서비스 데이터 | 공동 편집, 내보내기, 권한·요금 정책 |
| 문서 호스팅 서비스 | 파일 연동과 관리형 렌더·검색 | Git 연동 범위, 검색·테마·배포 제약 |
| 직접 빌드하는 문서 사이트 | 저장소 파일과 빌드 산출물 | 의존성·검사·호스팅을 관리할 여력 |

제품은 여러 방식에 걸칠 수 있다. 서비스가 파일을 내보낼 수 없거나 AI로 다룰 수 없다고
일괄 단정하지 않는다. 이 사이트는 한 사람이 Git diff로 본문을 검토하고 파일을 직접 보관하는
요구가 강해서 세 번째 방식을 선택했다.

## 갈림길이 되는 질문들

1. 편집자가 Markdown·Git을 사용할 수 있는가?
2. 학습 노트가 독립 사이트인가, 기존 앱의 일부인가?
3. 문서 버전별 병행 제공이나 API 자동 생성이 핵심인가?
4. 검색·테마를 조립하고 유지할 비용을 얼마나 감당할 수 있는가?

예를 들어 화면 편집이 핵심인 팀에 파일 기반 편집을 강요하면 좋은 검색도 기여 장벽을 해결하지 못한다.
반대로 코드와 문서를 같은 변경으로 검토하고 싶다면 저장소 파일이 직접 연결되는 방식이 유리하다.

## 왜 Starlight였나

이 사이트는 여러 학습 주제, 한국어 검색, 코드·표·다이어그램, 로컬 검증을 원했다.
[Starlight는 Pagefind 검색을 기본 제공](https://starlight.astro.build/guides/site-search/)하므로
별도 검색 서비스를 준비하지 않고 빌드 결과를 검색할 수 있다.
[Docusaurus의 검색 안내](https://docusaurus.io/docs/search)는 Algolia와 자체·지역 검색 선택지를
설명한다. 따라서 Docusaurus로 불가능해서가 아니라 이 프로젝트에서 고를 검색 구성이 적어서 택했다.

덱별 사이드바는 Starlight 코어가 아니라 `starlight-sidebar-topics` 플러그인이고,
폴더별 `_deck.mjs`에서 사이드바·랜딩을 파생하는 loader는 **이 저장소의 코드**다.
이 편의를 Starlight를 설치하기만 하면 주어지는 기능으로 혼동하지 않는다.

Astro의 정적 컴포넌트 모델도 본문 중심 사이트에 맞는다. 다만 검색·탭·확대에는 브라우저 JS가
쓰이므로 사이트 전체가 JS 0이라는 뜻은 아니다. 자세한 경계는 [Astro](/starlight/astro/)에서 본다.

## AI가 작성자일 때

파일은 에이전트가 직접 읽고 diff로 수정하기 쉽고, 빌드는 문법·링크 오류를 확인하는 신호가 된다.
그렇다고 빌드가 사실 정확성까지 판정하지는 않는다. 독자·학습 결과·근거를 요청에 담고 작성 뒤
의미 리뷰를 해야 한다. [Coding Agents의 요청 예제](/coding-agents/execution-and-resume/)가 이 흐름을 보여 준다.

특정 도구에서 AI가 더 정확하다거나 빌드가 더 빠르다는 결론은 같은 조건의 측정이 있어야 한다.
이 덱은 그런 비교 실험을 하지 않았다. 버전·코드·작성 지침을 확인하는 것은 모델의 사전 지식이
맞을 것이라는 기대보다 재현 가능한 출발점이다.

## 선택이 달라지는 경우

| 상황 | 먼저 확인할 조건 |
|---|---|
| 비개발자 공동 편집 | 화면 편집·권한·내보내기 |
| 제품 버전별 문서를 오래 병행 | 버전 분기·탐색·링크 관리 |
| 기존 앱 안의 문서 | 기존 라우터·컴포넌트·배포와 통합 |
| API 레퍼런스가 중심 | 코드에서 문서를 생성하는 경로 |
| 독립 학습 노트 | 검색·파일 소유·작성과 검증 비용 |

운영 중에 다른 도구를 고를 때는 새 이점 외에 MDX 문법, 공용 컴포넌트, 검색·D2 통합,
옛 URL 호환의 이전 비용을 계산한다. 기능 하나가 좋다는 이유만으로 전체 이전이 유리해지지는 않는다.

## 이해 확인

공동 편집이 불편한 것이 문제인데 빌드 시간이 빠른 도구로 옮기면 해결될까?
먼저 편집 경로와 기여자의 준비 수준을 봐야 한다. 현재 문제와 선택 기준이 연결돼야 비교가 의미 있다.
