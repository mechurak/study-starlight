> 이 덱이 남기려는 것은 Starlight 지식이 아니라 **이 사이트를 계속 고칠 수 있는 상태**다

## 덱을 관통한 한 문장

**콘텐츠 · 구조 · 표현은 다른 층이고, 층마다 판정자가 다르다.**

- 콘텐츠(`src/content/docs/`)는 마크다운/MDX — 문법은 빌드가, 렌더는 브라우저가 판정한다
- 구조(`astro.config.mjs`)는 topics와 사이트 설정 — slug 어긋남은 빌드가 잡는다
- 표현(`src/components/` · `custom.css`)은 컴포넌트와 스타일 — 라이트/다크 두 모드가 판정한다

무언가 이상할 때 "어느 층의 문제인가"부터 물으면, 뒤질 파일과 문서가 바로 좁혀진다.

## 새 덱을 추가하는 절차

이 레포에서 가장 자주 반복될 작업이라 절차로 박아 둔다.

<Steps>

1. `src/content/docs/<덱이름>/` 을 만들고 `index.mdx`(개요)와 본문 페이지를 넣는다

   장 파일명은 `00-intro.mdx` 부터 번호로. 처음부터 전부 `.mdx`로 만든다.
   덱 index의 "구성" 절은 mermaid가 아니라 `<DeckMap>`으로.

2. `astro.config.mjs`의 topics 배열에 덱을 등록한다

   `label` · `link` · `icon` · `items`(그룹 라벨 + slug 문자열). 등록하지 않으면
   `Failed to find the topic` 으로 빌드가 실패한다 — 잊어도 잡힌다.

3. 랜딩(`src/content/docs/index.mdx`)에 카드와 hero 액션을 추가한다

4. 덱 고유의 규칙이 있으면 `_baseline.md`를 덱 폴더에 만든다

   기준 버전 고정, 서술 규칙, "왜 이렇게 쓰였는가" — CLAUDE.md가 아니라 여기에.
   `_` 파일이라 빌드에는 안 잡힌다.

5. `pnpm build` 로 판정하고, 장의 리듬(인용구 → TermIntro → h2 5~9개 → 요약 → LinkCard)을 유지한다

</Steps>

## 치트시트

### 명령

| 하려는 것 | 명령 |
|---|---|
| dev 서버 (백그라운드) | `astro dev --background` → `astro dev stop` / `status` / `logs` |
| 전 페이지 판정 | `pnpm build` |
| 배포와 같은 물건 확인 | `npx serve dist -l 4323` |
| 깨진 굵게 찾기 | `grep -rho '\*\*[^<*]\{0,45\}' dist --include=index.html \| sort -u` |
| 제목 고치기 전 앵커 참조 확인 | `grep -rn '#앵커-slug' src/content/docs/` |
| 배포 | `main` 푸시 (요청받았을 때만) — 브랜치 푸시는 preview |

### 빌드가 통과해도 깨져 있는 것들

여덟 장에서 반복해 나온, **조용히 깨지는** 지점만 모으면 —

| 증상 | 원인 | 장 |
|---|---|---|
| mermaid가 회색 코드 블록 | config에서 `mermaid()`가 `starlight()` 뒤 | 2 |
| 다이어그램이 다크 모드에서 안 읽힘 | classDef에 `color:` 누락 | 5 |
| 화면에 `**` 가 그대로 보임 | 닫는 `**` 앞 문장부호 + 뒤 조사 | 4 |
| 컴포넌트 안 내용이 코드 블록으로 | JSX 자식 마크다운 들여쓰기 | 4 |
| 절 링크가 조용히 죽음 | 제목 수정으로 앵커 slug 변경 | 7 |
| 제목 옆 Badge 후 링크 변경 | `<Badge>` 앞에 공백 — slug 끝에 `-` | 5 |
| 검색에 새 글이 안 나옴 (배포) | 인덱스는 빌드 산출물 — 배포가 안 된 것 | 8 |

## 이 덱이 스스로에게 거는 검증

이 덱의 예제는 전부 이 레포다(0장). 그래서 레포가 바뀌면 이 덱도 낡는다 —
컴포넌트 목록(6장), 배포 설정(8장), 덱 추가 절차(이 장)를 고쳤다면
`starlight` 덱의 해당 대목도 같이 고친다. 기준은 덱 폴더의 `_baseline.md`에 있다.
