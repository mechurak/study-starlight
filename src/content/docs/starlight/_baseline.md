# starlight 덱의 기준

`starlight` 덱을 고치기 전에 읽는다.

**Starlight 0.41 · Astro 7 (2026년 8월)** 이 기준이다. 그리고 이 덱의 예제는
전부 **이 레포 자체**다 — 예제 코드·경로·설정이 레포 실물과 어긋나면 **레포가 맞다.**
레포를 고쳤으면 이 덱의 해당 대목도 같이 고친다 (특히 3장 구조, 6장 컴포넌트 목록, 8장 배포).

각 장 첫머리의 `<TermIntro>` 상자가 의무다 — 규칙은 AGENTS.md "덱" 절.

이 덱은 "Starlight 공식 문서의 요약"이 아니다 — **왜 이 도구를 골랐고 여기서 어떻게
쓰는가**가 축이다. 공식 문서와 겹치는 API 나열을 늘리지 말고, 링크로 처리한다.
