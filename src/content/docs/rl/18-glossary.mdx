## 기본 개념

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| 강화학습 | Reinforcement Learning | 정답 대신 **점수(보상)** 로 배우는 방식 | [0](/rl/00-intro/) |
| 에이전트 · 환경 | Agent · Environment | 행동하는 쪽과 반응하는 쪽. 둘의 왕복이 유일한 데이터원 | [0](/rl/00-intro/) |
| **MDP** | Markov Decision Process | 문제를 적는 표준 양식 — `S, A, P, R, γ` | [2](/rl/02-mdp/) |
| 마르코프 성질 | Markov Property | "지금 상태만 보면 과거는 몰라도 된다". **설계로 만들어 내는 것** | [2](/rl/02-mdp/) |
| POMDP | Partially Observable MDP | 상태를 다 못 보는 경우. 현실 문제는 대부분 여기 | [2](/rl/02-mdp/) |
| 정책 | Policy · π | "이 상태에서 무엇을 하나". 학습의 최종 산출물 | [2](/rl/02-mdp/) |
| 리턴 | Return · G | 앞으로 받을 보상을 할인해 다 더한 값 | [2](/rl/02-mdp/) |
| 할인율 | Discount Factor · γ | 미래를 얼마나 쳐 줄지. **시야 길이** `1/(1−γ)` | [2](/rl/02-mdp/) |
| `terminated` · `truncated` | — | **문제 정의상 끝**과 **잘렸을 뿐**의 구분. 뭉개면 버그 | [2](/rl/02-mdp/) · [9](/rl/09-training/) |
| 가치 함수 | Value · V(s) | 이 자리가 얼마나 좋은가 | [3](/rl/03-value/) |
| 행동 가치 | Action Value · Q(s,a) | 이 자리에서 이 행동이 얼마나 좋은가 | [3](/rl/03-value/) |
| **벨만 방정식** | Bellman Equation | 가치를 **"지금 보상 + 다음 가치"** 로 쓴 재귀 | [3](/rl/03-value/) |
| TD 학습 | Temporal Difference | 한 스텝만 가 보고 추정을 고치는 것 | [3](/rl/03-value/) |
| 부트스트래핑 | Bootstrapping | 추정치로 추정치를 고치는 것. 빠르지만 불안정 | [3](/rl/03-value/) |
| **어드밴티지** | Advantage · A(s,a) | `Q − V`. **평균보다 얼마나 나은가** — 실질적 학습 신호 | [5](/rl/05-policy-gradient/) |
| GAE | Generalized Advantage Estimation | 여러 n-스텝을 `λ`로 섞은 어드밴티지 추정 | [3](/rl/03-value/) · [6](/rl/06-ppo-sac/) |
| 탐색과 활용 | Exploration / Exploitation | 새로 시도할까, 아는 최선을 할까 | [3](/rl/03-value/) |
| on-policy · off-policy | — | **지금 정책의 데이터로만** 배우는가, 남의 데이터도 되는가 | [3](/rl/03-value/) |
| 공로 배분 | Credit Assignment | 좋은 결과가 어느 행동 덕인지 나누는 일 | [1](/rl/01-why/) |
| 밴딧 | Multi-Armed Bandit | 다음 상태가 없는 단발 선택 문제 | [1](/rl/01-why/) |

## 알고리즘

| 알고리즘 | 갈래 | 한 줄 | 행동 | 정책 | 장 |
|---|---|---|---|---|---|
| Q러닝 | 가치 | 벨만 최적 방정식을 TD로 | 이산 | off | [4](/rl/04-value-based/) |
| SARSA | 가치 | 실제로 한 행동으로 배운다 | 이산 | on | [4](/rl/04-value-based/) |
| **DQN** | 가치 | Q러닝 + 신경망 + 재생 버퍼 + 타깃망 | 이산 | off | [4](/rl/04-value-based/) |
| Double DQN | 가치 | 고르기와 평가를 분리해 **과대추정**을 잡는다 | 이산 | off | [4](/rl/04-value-based/) |
| REINFORCE | 정책 | 좋았던 행동의 확률을 올린다 | 둘 다 | on | [5](/rl/05-policy-gradient/) |
| A2C | 액터-크리틱 | 어드밴티지로 분산을 줄인다 | 둘 다 | on | [5](/rl/05-policy-gradient/) |
| **PPO** | 액터-크리틱 | 확률 비율을 **잘라** 한 걸음을 제한 | 둘 다 | on | [6](/rl/06-ppo-sac/) |
| TD3 | 액터-크리틱 | 쌍둥이 크리틱 + 지연 갱신 + 타깃 평활화 | 연속 | off | [6](/rl/06-ppo-sac/) |
| **SAC** | 액터-크리틱 | 보상 + **엔트로피**를 같이 키운다 | 연속 | off | [6](/rl/06-ppo-sac/) |
| BC | 모방 | 시연을 지도학습으로 흉내 | 둘 다 | — | [7](/rl/07-offline-model/) · [16](/rl/16-imitation-vla/) |
| CQL | 오프라인 | 못 본 행동의 Q에 **벌점** | 둘 다 | 오프라인 | [7](/rl/07-offline-model/) |
| IQL | 오프라인 | `max`를 아예 쓰지 않는다 | 둘 다 | 오프라인 | [7](/rl/07-offline-model/) |
| Dreamer · MBPO | 모델 기반 | 배운 세계 모델 안에서 연습 | 둘 다 | — | [7](/rl/07-offline-model/) |
| 확산 정책 | 모방 | 행동 시퀀스를 확산 모델로 생성 | 연속 | — | [16](/rl/16-imitation-vla/) |

### 고르는 기준 요약

| 상황 | 고른다 |
|---|---|
| 이산 행동 + 샘플이 비싸다 | DQN 계열 |
| 연속 행동 + **시뮬레이터로 샘플을 대량 생산** | **PPO** |
| 연속 행동 + 샘플이 아깝다 | **SAC** (안 되면 TD3) |
| 새 샘플을 **아예 못 뽑는다** | 오프라인 RL (IQL → CQL 순으로 시도) |
| **정답 시범을 보일 수 있다** | 모방학습 (BC · 액션 청킹 · 확산 정책) |

## 학습과 평가

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| 경험 재생 | Experience Replay | 버퍼에 쌓고 무작위로 꺼내 학습 | [4](/rl/04-value-based/) |

| 치명적 삼요소 | Deadly Triad | **함수 근사 + 부트스트래핑 + off-policy** = 발산 위험 | [4](/rl/04-value-based/) |
| 클리핑 | Clipping | PPO가 확률 비율을 잘라 스텝을 제한하는 것 | [6](/rl/06-ppo-sac/) |
| 엔트로피 보너스 | Entropy Bonus | 정책이 한쪽으로 쏠리는 것을 막는 항 | [5](/rl/05-policy-gradient/) |
| 벡터 환경 | Vectorized Env | 환경 여러 개를 배치로 굴리는 것 | [9](/rl/09-training/) |
| 래퍼 | Wrapper | 관측·보상을 가공하는 얇은 층. **정규화가 여기** | [9](/rl/09-training/) |
| SPS | Steps Per Second | 초당 환경 스텝. 처리량 지표 | [9](/rl/09-training/) |
| 설명 분산 | Explained Variance | 크리틱이 리턴을 얼마나 맞히나. **0 근처면 무용지물** | [9](/rl/09-training/) |
| **리워드 해킹** | Reward Hacking | 보상은 최대인데 원한 일은 안 하는 해법 | [8](/rl/08-reward/) |
| 보상 셰이핑 | Reward Shaping | 중간 과정에 점수를 주는 것 | [8](/rl/08-reward/) |
| 잠재 기반 셰이핑 | Potential-Based Shaping | `γΦ(s') − Φ(s)` 형태. **최적 정책이 안 바뀐다** | [8](/rl/08-reward/) |
| 커리큘럼 | Curriculum | 쉬운 것부터 점점 어렵게. **셰이핑보다 안전** | [8](/rl/08-reward/) |
| 분포 이탈 | Distributional Shift | 데이터에 없는 행동을 하려 드는 것 | [7](/rl/07-offline-model/) |
| OPE | Off-Policy Evaluation | 굴려 보지 않고 정책을 평가하는 것 | [7](/rl/07-offline-model/) |
| IQM | Interquartile Mean | 상하위 25%를 버린 평균. **권장 보고 통계** | [10](/rl/10-evaluation/) |
| 절제 실험 | Ablation | 부품을 빼 보며 기여를 가리는 실험 | [10](/rl/10-evaluation/) |
