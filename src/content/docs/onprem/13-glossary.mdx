## 온프렘 일반

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| 온프렘 | On-premises | 자체 인프라에서 직접 운영하는 것 | [0](/onprem/00-intro/) |
| 관리형 서비스 | Managed Service | 사업자가 설치·운영까지 책임지고 API만 빌려주는 것 | [1](/onprem/01-why/) |
| CCM | Cloud Controller Manager | 쿠버네티스와 클라우드 자원을 잇는 컴포넌트. **온프렘엔 이게 없다** | [1](/onprem/01-why/) |
| 에어갭 | Air-gap | 인터넷과 물리적으로 끊긴 환경 | [0](/onprem/00-intro/) |
| egress 프록시 | Egress Proxy | 내부→외부 트래픽을 대신 내보내는 사내 중계 | [4](/onprem/04-tls-dns/) |
| SLO | Service Level Objective | 스스로 정한 서비스 목표치 | [1](/onprem/01-why/) |
| 실패 도메인 | Failure Domain | 함께 죽는 범위. 백업을 여기에 같이 두면 안 된다 | [11](/onprem/11-backup/) |
| DR | Disaster Recovery | 사이트·클러스터 전체를 잃었을 때 다른 환경에서 되살리는 계획과 절차 | [11](/onprem/11-backup/) |

## ① 바닥 — 클러스터 · 네트워크 · 스토리지

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| 쿼럼 | Quorum | 과반수. etcd는 노드 과반이 살아야 쓰기가 된다 | [2](/onprem/02-foundation/) |
| VIP | Virtual IP | 살아 있는 한 대가 넘겨받는 떠다니는 IP | [2](/onprem/02-foundation/) |
| CNI | Container Network Interface | 파드 네트워크 플러그인 규격 (Calico · Cilium) | [2](/onprem/02-foundation/) |
| CSI | Container Storage Interface | 스토리지 드라이버 표준 | [2](/onprem/02-foundation/) |
| 블록 · 파일 · 오브젝트 | Block · File · Object | 스토리지 세 계층. **오브젝트는 마운트하지 않는다** | [2](/onprem/02-foundation/) · [6](/onprem/06-minio/) |
| RWO · RWX | ReadWriteOnce · ReadWriteMany | 한 노드만 / 여러 노드가 동시에 | [2](/onprem/02-foundation/) |
| reclaimPolicy | — | PVC를 지울 때 실제 디스크를 지울지(`Delete`) 남길지(`Retain`) | [2](/onprem/02-foundation/) |
| erasure coding | 소거 부호 | 데이터 + 패리티로 쪼개 분산. 일부가 죽어도 복원 | [6](/onprem/06-minio/) |

## ③ 상태 — 오브젝트 스토리지와 데이터베이스

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| S3 API | Simple Storage Service API | 오브젝트 스토리지의 사실상 표준 HTTP 인터페이스 | [6](/onprem/06-minio/) |
| 버킷 · 객체 · 키 | Bucket · Object · Key | 그릇 · 데이터 · 이름. **키의 `/`는 폴더가 아니라 접두사** | [6](/onprem/06-minio/) |
| path-style | — | `호스트/버킷/키` 형식. **온프렘은 대개 이걸 켠다** | [6](/onprem/06-minio/) |
| 라이프사이클 | Lifecycle | "N일 지난 객체는 삭제" 규칙. 디스크가 차는 걸 막는 장치 | [6](/onprem/06-minio/) |
| 오퍼레이터 | Operator | 운영 절차를 컨트롤러 코드로 옮긴 것 | [7](/onprem/07-cnpg/) |
| CNPG | CloudNativePG | 쿠버네티스용 PostgreSQL 오퍼레이터 | [7](/onprem/07-cnpg/) |
| WAL | Write-Ahead Log | 데이터를 고치기 전에 먼저 남기는 변경 로그. 복제·복구의 기반 | [7](/onprem/07-cnpg/) |
| PITR | Point-In-Time Recovery | 베이스 백업 + WAL로 임의 시점 복구 | [7](/onprem/07-cnpg/) · [11](/onprem/11-backup/) |
| 페일오버 · 스위치오버 | Failover · Switchover | 죽어서 넘어감 / 계획적으로 넘김 | [7](/onprem/07-cnpg/) |
| 동기 · 비동기 복제 | Synchronous · Asynchronous | 커밋 때 레플리카를 기다리는지 | [7](/onprem/07-cnpg/) |

| ESO | External Secrets Operator | 외부 금고의 값을 Secret으로 만들어 주는 오퍼레이터. Git엔 참조만 | [10](/onprem/10-secrets/) |

| etcd 스냅샷 | — | 클러스터 오브젝트 전체를 뜬 파일. 복구는 최후 수단 | [11](/onprem/11-backup/) |
| Velero · Kopia | — | 리소스·PV 백업 도구 / 그 파일 백업 엔진 | [11](/onprem/11-backup/) |

| runbook | 실행 절차서 | 알림·증상별 확인·조치 순서 | [12](/onprem/12-ops/) |
