| node-exporter · kube-state-metrics | — | 노드 상태 / 쿠버네티스 오브젝트 상태를 내주는 두 exporter | [2](/observability/02-prometheus/) |
| ServiceMonitor · PodMonitor | — | "이걸 긁어라"를 선언하는 CRD | [2](/observability/02-prometheus/) |

| 기록 규칙 | Recording Rule | 무거운 쿼리를 미리 계산해 새 메트릭으로 저장 | [2](/observability/02-prometheus/) |

### PromQL 문법 요약

| 쓰는 것 | 무엇 |
|---|---|
| `이름{라벨="값"}` | 순간 벡터 — 지금 시점의 값들 |
| `이름[5m]` | 범위 벡터 — 지난 5분치. **함수 안에서만 쓴다** |
| `rate(x[5m])` · `increase(x[1h])` | counter의 **초당 속도** · **구간 증가량** |
| `sum by (l) (...)` · `sum without (l) (...)` | 라벨을 남기고 / 지우고 합친다 |
| `histogram_quantile(0.99, sum by (le, …) (rate(…_bucket[5m])))` | p99. **`le`를 남기는 것이 핵심** |
| `predict_linear(x[6h], 24*3600) < 0` | 추세를 외삽 — **"찰 것 같다"** |
| `absent(up{job="x"})` | 시계열이 **아예 없을 때** 참 |
| `topk(5, …)` | 상위 5개 |

**순서는 언제나 `rate` → `sum by` → `histogram_quantile`.**

## ② 로그 — Loki

| 용어 | 풀 이름 | 뜻 | 장 |
|---|---|---|---|
| 스트림 | Stream | **라벨 조합 하나 = 스트림 하나.** 로그는 스트림 단위로 뭉친다 | [3](/observability/03-loki/) |
| chunk | 청크 | 스트림의 로그를 뭉쳐 압축한 덩어리. **오브젝트 스토리지로 간다** | [3](/observability/03-loki/) |
| LogQL | Log Query Language | Loki 질의 언어. 네 단계로 읽는다 — 아래 요약 | [3](/observability/03-loki/) |
| 라인 필터 · 파서 | Line Filter · Parser | 본문 문자열로 거르기 / 필드를 꺼내기. **필터가 먼저여야 빠르다** | [3](/observability/03-loki/) |
| compactor | — | chunk 정리와 **보존 기간 적용**을 맡는 컴포넌트 | [3](/observability/03-loki/) |
| monolithic · SSD · microservices | — | Loki 배포 모드 셋. **monolithic → SSD 순으로 간다** | [3](/observability/03-loki/) |
| 테넌트 | Tenant | `X-Scope-OrgID`로 가르는 격리 단위. 팀·규정별 분리에 | [3](/observability/03-loki/) |
| ingester · querier | — | 인입을 받아 chunk로 만드는 쪽 / 질의를 처리하는 쪽 | [3](/observability/03-loki/) |
| ruler | — | 로그로 알림 규칙을 평가하고 Alertmanager로 보내는 컴포넌트 | [3](/observability/03-loki/) · [5](/observability/05-grafana/) |

### LogQL 문법 요약

| 단계 | 쓰는 것 | 무엇 |
|---|---|---|
| ① 스트림 선택 | `{namespace="prod", app="api"}` | **필수.** 읽을 chunk의 범위 |
| ② 라인 필터 | `\|=` `!=` `\|~` `!~` | 본문 문자열로 거른다. **파서보다 앞에** |
| ③ 파서 | `\| json` `\| logfmt` `\| pattern` `\| regexp` | 필드를 꺼낸다 |
| ④ 라벨 필터 | `\| status >= 500` | 꺼낸 필드로 다시 거른다 |
| ④ 출력 | `\| line_format "{{.msg}}"` | 보이는 줄을 다시 조립 |
| ④ 집계 | `sum by (app) (rate({…}[5m]))` | **로그를 세어 그래프로** |
| ④ 숫자 집계 | `quantile_over_time(0.99, {…} \| json \| unwrap duration_ms [5m])` | 꺼낸 필드를 숫자로 |

| head · tail 샘플링 | — | 시작할 때 결정 / **끝나고 결과를 보고** 결정 | [4](/observability/04-tempo/) |
| TraceQL | — | Tempo 질의 언어 — 아래 요약 | [4](/observability/04-tempo/) |
| 서비스 그래프 | Service Graph | 트레이스에서 자동 생성한 "누가 누구를 부르나" 지도 | [4](/observability/04-tempo/) |
| 스팬 메트릭 | Span Metrics | 트레이스에서 뽑아낸 요청 수·지연·에러율 | [4](/observability/04-tempo/) |

### TraceQL 문법 요약

| 쓰는 것 | 무엇 |
|---|---|
| `{ duration > 2s }` | 스팬 자체의 값 — `duration` · `status` · `name`은 접두사가 없다 |
| `{ resource.service.name = "orders" }` | **프로세스** 꼬리표로 고르기 |
| `{ span.http.route = "/orders" }` | **구간** 꼬리표로 고르기 |
| `A >> B` · `A > B` | B가 A의 **자손** / **직계 자식**인 트레이스 |
| `{ … } \| count() > 3` | 조건에 맞는 스팬이 3개 이상 — **N+1 질의 찾기** |
| `\| select(span.db.statement)` | 결과 표에 이 필드를 같이 보여 준다 |
