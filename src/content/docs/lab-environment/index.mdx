> 여러 덱에서 반복하는 **실습 환경 준비와 정리 방법을 운영체제별로 한곳에 모은다**

실습마다 Docker·kind 같은 도구의 설치법을 다시 적으면 명령이 금방 낡고, macOS와 Ubuntu의 차이가
한 장 안에서 뒤섞인다. 이 덱은 환경마다 **설치할 공식 문서 → 실행 준비 → 생성 → 확인 → 정리**를
운영체제별 준비 장과 공통 사용 장으로 나눠 제공한다. 개별 기술 덱에는 그 실습의 자원 요구량과
실행 시나리오만 남긴다.

현재는 첫 환경으로 **kind를 이용한 로컬 Kubernetes 실습**을 다룬다. 덱 이름을 Kubernetes에
가두지 않은 이유는 앞으로 데이터베이스, 메시징, AI 같은 다른 실습 환경도 이곳에 모으기 위해서다.

## 다른 덱과의 경계

예를 들어 관측 실습은 자기 운영체제에 맞는 장에서 kind를 준비한 뒤,
[관측 8장](/observability/08-lab-setup/)에서 LGTM 스택과 계측 앱을 올린다. CKA에서 kind로
연습할 수 있는 범위와 시험용 환경의 차이는 [CKA 0장](/cka/00-intro/)이 판단한다.

kagent를 연습할 때도 이 덱에서 Docker·kind·kubectl을 준비한 뒤 [kagent 실습 0장](/kagent-lab/00-lab-map/)으로
넘어간다. kagent 전용 cluster 이름·설치·Agent 시나리오·cleanup은 그 덱이 맡는다.
