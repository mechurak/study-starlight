> 여러 덱에서 반복하는 **실습 환경 준비와 정리 방법을 운영체제별로 한곳에 모은다**

실습마다 Docker·kind 같은 도구의 설치법을 다시 적으면 명령이 금방 낡는다. 이 덱은 환경마다
**설치할 공식 문서 → 실행 준비 → 생성 → 확인 → 정리**를 한 흐름으로 제공하고, macOS와 Ubuntu의
차이는 각 소제목의 탭에서 나란히 보여 준다. 개별 기술 덱에는 그 실습의 자원 요구량과 실행 시나리오만 남긴다.

현재는 첫 환경으로 **kind를 이용한 로컬 Kubernetes 실습**을 다룬다. 덱 이름을 Kubernetes에
가두지 않은 이유는 앞으로 데이터베이스, 메시징, AI 같은 다른 실습 환경도 이곳에 모으기 위해서다.

시나리오·cleanup은 그 덱이 맡는다.
