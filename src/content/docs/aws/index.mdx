<Thesis>AWS 운영은 작업할 권한과 발생한 비용을 확인하는 습관에서 시작한다.</Thesis>

리소스를 만드는 방법만 알아서는 계정을 오래 운영하기 어렵다. 콘솔은 열리는데 작업이 거부되거나,
인스턴스를 껐는데도 요금이 늘어나는 순간에는 **누가 무엇을 할 수 있는지**, **어떤 자원이 아직
비용을 만드는지**를 구분해야 한다.

이 덱은 개인 학습용 AWS 계정을 운영하면서 다시 찾아볼 주요 개념과 확인 절차를 모은다.
우선 IAM으로 일상 작업용 신원과 권한을 정리하고, 비용 페이지에서 청구·사용량·크레딧을 읽고
알림을 설정하는 법을 다룬다. VPC 페이지에서는 자원을 어디에 배치하고 어떤 경로와 규칙으로
연결하는지 익힌다. 서비스별 운영 팁은 이후 필요한 주제가 생길 때 장으로 확장한다.

## 기준과 범위

2026-09-07에 확인한 AWS 공식 문서를 기준으로 한다. 기본 대상은 **개인 학습용 단일 계정**이며,
명령 예시는 AWS CLI v2를 사용한다. Organizations를 쓰는 조직 계정은 권한과 비용 조회 범위가
다를 수 있으므로 각 장에서 관련 조건을 함께 확인한다.

콘솔 메뉴와 요금은 바뀔 수 있다. 본문 가까이에 둔 공식 링크로 현재 조건을 확인하고,
금액은 사용 리전·과금 단위·플랜을 맞춰 읽는다.
