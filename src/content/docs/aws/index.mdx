<Thesis>AWS 운영은 서비스의 자리와 관리 책임을 이해하고, 권한·비용·요청의 흐름을 연결하는 데서 시작한다.</Thesis>

리소스를 만드는 방법만 알아서는 계정을 오래 운영하기 어렵다. 콘솔은 열리는데 작업이 거부되거나,
인스턴스를 껐는데도 요금이 늘어나는 순간에는 **누가 무엇을 할 수 있는지**, **어떤 자원이 아직
비용을 만드는지**를 구분해야 한다.

이 덱은 개인 학습용 AWS 계정을 운영하면서 다시 찾아볼 주요 개념과 확인 절차를 모은다.
먼저 서비스·리소스·리전·관리 책임의 큰 그림을 잡고 IAM·비용·VPC로 운영 기반을 정리한다.
이어 **사진을 올리고 목록을 조회하는 앱**을 공통 예시로 컴퓨팅·저장소·서버리스 연결·앱 인증을 이해하고,
배포한 변경과 장애 원인을 추적하는 방법까지 연결한다.

## 기준과 범위

2026-09-07에 확인한 AWS 공식 문서를 기준으로 한다. 기본 대상은 **개인 학습용 단일 계정**이며,
명령 예시는 AWS CLI v2를 사용한다. Organizations를 쓰는 조직 계정은 권한과 비용 조회 범위가
다를 수 있으므로 각 장에서 관련 조건을 함께 확인한다.

콘솔 메뉴와 요금은 바뀔 수 있다. 본문 가까이에 둔 공식 링크로 현재 조건을 확인하고,
금액은 사용 리전·과금 단위·플랜을 맞춰 읽는다.

설명 흐름은 2026-02-24 강의 정리 자료 `Samsung_20260224.pdf`를 참고해 문서형 노트로 재구성했다.
서버에서 관리형 서비스로 넘어가는 비교와 서비스 사이의 호출 흐름을 살리고, 세부 동작은 본문에 연결한
AWS 공식 문서로 확인했다. 각 장은 개념과 확인 경로를 다루며 전체 앱 배포 실습이나 자격증 대비는 범위 밖이다.
