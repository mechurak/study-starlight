# AWS 덱 기준

## 기준 시점

- 2026-09-07에 AWS 공식 사용자 가이드·요금표를 확인했다.
- AWS 상용 리전의 개인 학습용 단일 계정을 기본으로 설명한다. Organizations와 팀 운영은
  권장 인증 방식과 권한 경계를 이해하는 데 필요한 만큼만 다룬다.
- CLI 예제는 AWS CLI v2 기준이다. 콘솔의 영어 메뉴명을 병기하며 위치·문구는 바뀔 수 있다.

## 서술 규칙

- 운영 중 다시 찾을 개념 → 확인 경로 → 실수와 대응 순서로 쓴다. 서비스별 기능 나열이나 시험 요약은 피한다.
- 사람의 인증은 임시 자격증명을 우선한다. IAM User + 관리자 그룹은 학습 계정의 선택 가능한
  설정 경로이며 최소 권한이나 장기 권장 구성으로 표현하지 않는다.
- root 사용자와 AWS 계정, IAM 사용자와 역할, 인증과 권한을 구분한다.
- 비용은 사용량·크레딧 적용 전 비용·크레딧·청구액을 구분한다. Budgets는 실시간 지출 차단기가 아니다.
- Free Tier는 2025-07-15 이전 계정과 이후 계정, Free/Paid 플랜을 구분한다.
- 단가는 리전·단위·조건 없이 일반화하지 않는다. 현재 금액이 필요하면 공식 요금표에 연결한다.
- 바뀔 수 있는 동작에는 본문 가까이 공식 근거를 단다. reviewedAt은 실제 확인한 날짜만 쓴다.
- 각 학습 본문은 Thesis와 TermIntro로 열고, index는 DeckMap을 사용한다.

## 범위

- 현재 범위는 IAM, 비용 확인·알림·리소스 정리, VPC 네트워크 기초와 연결 진단이다.
- VPC의 기본 예시는 상용 리전의 IPv4 네트워크다. NAT 배치는 zonal public NAT 기준임을
  명시하고 Regional NAT·IPv6의 차이를 별도로 설명한다.
- 실제 계정 생성·권한 변경·리소스 삭제는 독자가 자기 계정에서 판단해 수행하는 절차다.
- 조직 전체 거버넌스, 다중 VPC·하이브리드 네트워크 상세 설계, Terraform 입문, 자격증 대비는 현재 범위 밖이다.
